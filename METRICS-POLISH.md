# Полировка метрик — точечная отмена

Базовое состояние перед ТЗ от 23.10.2026: CSS v123, JS v53. Снимок исходных файлов: `../rollback-snapshots/metrics-polish-v124/`.

Команда «отмени полировку метрик» означает удалить только CSS-блок между `BEGIN METRICS_POLISH_V124` и `END METRICS_POLISH_V124` и увеличить версию CSS в `index.html`. Все прежние правила остаются в файле, поэтому исходное оформление вернётся без восстановления старого файла целиком.

Дополнение v128 / JS v54: запятая веса выделена в `.athlete-dashboard-weight-comma` и уменьшена до `.8em`. При полной отмене полировки также удалить функцию `athleteDashboardWeightNumberMarkup`, вернуть два присваивания `weightSlot.textContent` с `athleteFormatWeightNumber` в `athleteLoadCabinetDashboard` и увеличить версию JS. Исходный JS сохранён рядом со снимком CSS в `athlete.js`; более поздние изменения этого файла сохранять.

Изменения ограничены `.athlete-dashboard-summary` и её потомками. Размеры и положение внешнего контейнера, разделитель, PNG-источники, данные, расчёты и остальной экран сохранены.

Скриншоты и измерения до/после: `../metrics-polish-review/`. Это реальные снимки локального приложения в Chrome на мобильной ширине. Для сравнения заданы CSS-отступы Telegram: верх 59 + 44 px, низ 34 px. Нативный интерфейс Telegram браузер не воспроизводит.

Проверены ширины 360, 375, 393 и 430 px. На них внешний прямоугольник карточки, положение и высота разделителя и прямоугольники остальных блоков совпадают с исходными. На 393 px карточка имеет размер 365 × 88 px, внутренние боковые отступы — по 10 px. Числа и подписи совпадают по вертикали; шрифт чисел — 700. Семь индикаторов, активные ПН и СР, содержимое SVG графика и высота графика 26 px сохранены. Ошибок JavaScript при просмотре нет.

Сравнение снимков: `../metrics-polish-review/comparison-393.png`. Попиксельная разница вне карточки не нулевая: есть небольшие различия растеризации. Утверждение о сохранении остальных блоков основано на совпадении геометрии, визуальном сравнении и области действия CSS, а не на побитовом совпадении скриншотов.
